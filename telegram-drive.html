📋 Cara Setup (5 menit)

  1. Buka @BotFather di Telegram
  2. Ketik /newbot dan ikuti instruksi
  3. Copy Bot Token dari BotFather
  4. Buat Private Channel di Telegram (sebagai folder)
  5. Add bot ke channel (Settings → Administrators → Add Admin)
  6. Ketik /start ke bot Anda
  7. Masukkan Bot Token dan Channel ID di bawah
Dapatkan Channel ID dengan forward pesan channel ke @userinfobot
